# /adopt-report

Explain or extend the **adoption report** (read path) without changing how
events are written — unless the user also requests `/adopt-event`.

Typical work:

- Clarify metric definitions (`references/metrics.md`)
- Add a table section mapping an existing RPC
- Improve `/adoption` layout / copy (presentation only)
- Adjust period labels or empty states

Do not invent KPIs the database cannot compute.
